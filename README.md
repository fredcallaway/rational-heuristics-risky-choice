# Automatically Deriving Resource-Rational Heuristics for Risky Choice

This repository contains code and data for the analyses for "Automatically Deriving Resource-Rational Heuristics for Risky Choice", 
which is currently under review ([preprint](https://psyarxiv.com/mg7dn)).

Model simulations can be generated by running `julia -p auto run_model.jl` in the julia/ directory. Note that this takes a long time even on a server with many cores.

Figures and statistical results can be generated by running `python3 main.py` in the python/ directory.

## Regenerating statistics only (using the existing processed `trials.csv`)

`main.py` re-runs data processing, figures (including the slow k-means clustering), and the
full statistics suite. To regenerate only the corrected statistics from the
already-processed `data/human/1.0/processed/trials.csv` — without reclustering — run the
individual functions from the `python/` directory:

```bash
cd python
# Issue 2: Exp1 strategy logistic regressions (requires Rscript + the lme4 R package;
# shells out to ../R/logistic_regression.R, then writes stats/exp1/1/<strategy>-<param>.txt)
python -c "import cfg, run_statistics as rs; rs.exp1_strategy_logistic_regression(cfg.exp1)"

# Issue 4: Figure B1 Cohen's kappa, both participant and model files
# (also rewrites figs/exp1/confusion_mat_kmeans-strategy.png; reads the cached cluster
# labels in trials.csv, so it does NOT recluster)
python -c "import cfg, make_figures as mf; mf.exp1_strategyVsKmeans_confusion_matrix(cfg.exp1)"
```

Notes:
- Both commands read `cfg.exp1.human` = `../data/human/1.0/processed/trials.csv`, so they use
  the existing processed data; run them from `python/` so the relative paths in `cfg.py` resolve.
- Do **not** run `main.py` or `run_statistics.statistics()` for this: they trigger the slow
  clustering and hit an interactive `pdb.set_trace()` in `under_performance`.
- If `Rscript`/`lme4` is unavailable, the logistic-regression function falls back to parsing the
  cached dump in `stats/exp1/dump/1/`, which may be stale — confirm `which Rscript` first.

A pinned pip environment is provided in `python/env/requirements.txt` with Python pinned via `python/env/.python-version`.

Example setup:

```bash
cd python/env
pyenv install -s 3.7.3
pyenv local 3.7.3
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
